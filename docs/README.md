# Dokumentasi Waybot

Dokumen kerja proyek, dari riset sampai hasil uji. Kode ada di `src/`.

- `00-requirements.md` — kebutuhan, alur final, kriteria terima
- `01-research-wayground.md` — temuan riset langsung (alur, API, DOM, anti-cheat, risiko)
- `02-architecture.md` — desain Rust, modul, state machine, agen halaman, anti-deteksi
- `03-plan.md` — fase, matriks uji, hasil eksekusi
- `04-live-test-checklist.md` — verifikasi live per tipe soal & skenario
- `05-decisions.md` — ADR
- `evidence/` — contoh respons API asli
- `research-probe/` — skrip Python sementara untuk koneksi Marionette (bukan aplikasi)
